C6500XK profile builder

Enter the vendor ID and equipment ID that your own unit reports, pick the PON slot, and this page writes the profile and the matching environment commands. It fills in model constants that are already known; it does not invent per-unit values.

Runs entirely in this tab, no network requests

    What this page does and does not do
    
    
      
      
    • It rewrites exactly three kinds of value in a profile whose other rows are model constants: the vendor ID, the equipment ID, and the instance numbers that encode the PON slot.
      • 
      
    • It leaves the ONU-G serial at 00000000 on purpose. The daemon derives the serial from the PLOAM serial, and a literal here conflicts with your own registration.
      • 
      
    • It writes the same values as 8311_vendor_id and 8311_equipment_id commands, because the boot script copies those out of the environment and overwrites the profile rows.
      • 
      
    • It does not generate VLANs, login credentials, registration IDs, service rates or GEM identifiers. Those are owned by the OLT and are replayed at runtime.
      • 
      
    • Nothing you type is stored, transmitted or logged. There is no analytics, no cookie, no storage call and no request after the page loads. The policy in the page header blocks connections outright.
      • 
      
    • The result is a mirror of one model, validated on one line against one OLT. It is not a guarantee of provisioning, and it is not a substitute for reading your own unit first.
